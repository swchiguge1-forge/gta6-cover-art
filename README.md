# Neon Coast Cover Studio

Entry for make.fun `gta6-cover-art-01`: a GTA-style cover maker that runs
entirely offline in the browser.

Pick your photos, choose one of four poster layouts (Quad Grid, Hero +
Trio, Full Bleed, Tilted Snaps) and one of five Vice-City grades (Vice
Sunset, Neon Nights, Golden Hour, Mono Noir, Palm Dusk), set the title,
subtitle and badge, and export the cover as a PNG at 1080x1080, 1080x1350
or 1920x1080.

## Run

```sh
node serve.ts
# open http://localhost:8080
```
