Neon Coast Cover Studio — a GTA-style cover maker that runs fully offline
in the browser. Drop in your photos, pick one of four poster layouts (Quad
Grid, Hero + Trio, Full Bleed, Tilted Snaps) and one of five Vice-City
grades (Vice Sunset, Neon Nights, Golden Hour, Mono Noir, Palm Dusk), set
the title, subtitle and badge, then export the finished cover as a PNG at
1080x1080, 1080x1350 or 1920x1080.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
